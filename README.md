# Cliques

### Description
A web service meant to create chat groups, assign roles, log chat messages, and integrate the chats into other media. Supporting filtering for users, for user-defined groups, and for specific messages. Allowing input operations to create groups, to send messages and to delete messages. Designed for tech-savvy users and/or private groups seeking a flexible messaging API.
