# What needs specific security checks?
## Who has the right to do what?

- Users: Anyone can create an account as long as the email is not already in use. A profile should be seen by any user, but only modified or deleted by its owner;  
- Groups: Any user without a warning can create a group. A group and its members count should be seen by any user, but its contents should only be modified or deleted by its members;
- Channels: Can only be seen and modified by its members, but only members without a warning can delete it;
- Messages: can only be seen by the channel members where the message was sent. Only the sender has the right to create, modify or delete its content.
- Memberships: a user can only access, modify or delete their own memberships.
